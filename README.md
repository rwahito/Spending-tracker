# Expense Tracker (Excel)

A personal expense tracking tool built in Microsoft Excel to help monitor daily spending and encourage better financial habits. The workbook features an entry form for recording transactions, a VBA macro (**Collect_data**) that automatically posts entries to a data table, pivot tables for expense summarization, and a dashboard (currently in development) for visualizing spending patterns.

## Tools:
1. Excel for:
   *Macros, data entry, data validation, data visualization*
